# Teste-jue RPG

**Teste-jue RPG: As Lendas de Valoria** is a retro fantasy turn-based Android RPG game built with Kotlin and Jetpack Compose.

## Features
- **4 Character Classes**: Guerreiro (Warrior), Mago (Mage), Ladino (Rogue), and Paladino (Paladin), each with unique skills, stats, and playstyles.
- **Tactical Turn-Based Combat**: Dynamic battle system with normal attacks, class spells, defensive guarding, potion usage, retreat chance, and real-time combat logs.
- **Dungeon Exploration**: Multi-floor dungeon crawl featuring monsters, bosses, ancient treasure chests, mystic shrines, and dangerous traps.
- **Equipment & Inventory**: Weapons, armor, shields, and accessories across Common, Rare, Epic, and Legendary rarities.
- **Town of Valoria**: Visit the Blacksmith to buy gear, Alchemist for potions, Tavern to rest and fully heal HP/MP, and Quest Board to claim bounties.
- **Progression**: Earn EXP, level up, and allocate attribute points to Strength, Agility, Intellect, and Vitality.
- **Auto-Save**: Progress is saved locally so players can continue their journey anytime.
