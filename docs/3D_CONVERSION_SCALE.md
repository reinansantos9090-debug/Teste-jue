## Direção de gameplay

A referência estrutural pesquisada para a conversão inclui Rooftop HQ, Portal, Expeditions, Rifts, Versus, Upgrade Cores, Wardrobe, Elite Hunter Path, Daily Goals, Weapon Sprints e Events. Esses conceitos estão sendo reinterpretados para um jogo single-player totalmente offline com conteúdo original.

O código não copia personagens, mapas, modelos, áudio, código-fonte ou outros assets proprietários de mo.co.
