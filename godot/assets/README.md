# Aetheria: Echoes — Asset Pipeline

The game uses original visual and audio assets. The Godot runtime can currently build
lightweight stylized meshes procedurally, while this directory is the contract for
production assets.

## Character pipeline
- modular body/head pieces
- 12 wardrobe styles
- weapon attachments
- idle, locomotion, attack, hit, dodge and skill animation clips

## Environment pipeline
- rooftop HQ
- portal/arena geometry
- five original biome families
- low-cost props and repeated vegetation

## VFX/audio pipeline
- hit bursts
- skill bursts
- portal energy
- boss phase effects
- procedural fallback SFX for fully offline operation

Do not import or copy proprietary game files, extracted assets, textures, models or code.
